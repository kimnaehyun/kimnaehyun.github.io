지도 인스턴스 중복 생성 문제

▶ 해결

useRef로 맵 인스턴스 참조를 보관하고, ref가 이미 존재하면 초기화 코드 건너뜀 → 단일 인스턴스 유지

refreshToken 없는 API에서 보안 UX 구현

▶ 해결

쿠키에 1시간 만료 설정 + setTimeout 1분 주기 체크 → 만료 5분 전 모달 표시 → 연장 또는 자동 로그아웃 처리

PostgreSQL Trigger 알림 중복 및 대상 필터링

댓글 작성자 본인, 토론 작성자, 기존 댓글 참여자 등 알림 대상을 정확히 분리해야 했고, Supabase에서 트리거 디버깅이 어려움

▶ 해결

DISTINCT · EXISTS · != 조건 조합으로 쿼리 최적화, 테스트 케이스를 테이블에 수동 삽입하며 로직 검증 → 중복 없는 알림 자동 생성 완성
